Beat 1 · Cast

Meet the cast

Named BLS keys stay in this process. Foreign members can be pk-only — they sit on a council, but only a signing identity can approve.

Click a row to append its name to a focused member/signer field on later beats.

Values to enter

Name Short label (alice). Used everywhere as a signer/member reference.
Import name Label for a foreign member that only has a public key.
Public key Base58 or 96-byte hex from another machine’s identity export.

Beat 2 · Form council

Form the treasury

Register an M-of-N member set. Anyone may create the account — naming keys grants the creator no special power.

Values to enter

Members Comma-separated identity names that already exist (or pk-only imports).
Threshold How many must sign later (e.g. 2 for 2-of-3).

After success, note next_id − 1 as your account id for later beats.

Developer · Rotate

                  
Rotate the council

                  
Current members authorize a new set over a registry-owned nonce digest. Panic strings include member_matches / sigs_ok.

                

                

                  
Values to enter

                  

                    
                      Account id
                      Treasury to govern.
                    
                    
                  

                  

                    
                      New members
                      Desired post-change set (story: drop Bob → alice,carol).
                    
                    
                  

                  

                    
                      New threshold
                      How many of the new set must sign after the change.
                    
                    
                  

                  

                    
                      Signers
                      Quorum of the current members (before the change).
                    
                    
                  

                  

                    
                  

                  
    
                    
  • Under-threshold — one signer when threshold is 2 → panic sigs_ok=1.
    • 
                    
  • Happy rotate — enough current signers → members update, nonce++.
    • 
                    
  • Stale nonce — after a rotate, a stale digest fails (sigs_ok=0).
    • 
                    
  • Ex-member — removed member as signer → member_matches drops.
    •
