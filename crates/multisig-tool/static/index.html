Chapter 2

Form the treasury

Register an M-of-N member set on-chain. Anyone may create the account — naming keys grants the creator no special power.

Values to enter

Members Comma-separated identity names that already exist (or pk-only imports).
Threshold How many must sign later (e.g. 2 for 2-of-3).

After success, note next_id − 1 as your account id for the other chapters.

Chapter 4

          
Approve a payout

          
Each signer does sk.sign(msg). On-chain: one verify_bls per signer. Prefer Rotate or Multi-person for crisp pass/fail.

        

        

          
Values to enter

          

            
              Account id
              Treasury from Form council.
            
            
          

          

            
              Message
              UTF-8 text the signers agree on (e.g. approve payout #42).
            
            
          

          

            
              Signers
              At least threshold local signing names.
            
            
          

          

            
            
          

          
If diagnose shows members matched but sigs_ok=0, treat free-read as untrusted.

Chapter 6

          
Rotate the council

          
Current members authorize a new set over a registry-owned nonce digest. Panic strings include member_matches / sigs_ok.

        

        

          
Values to enter

          

            
              Account id
              Treasury to govern.
            
            
          

          

            
              New members
              Desired post-change set (story: drop Bob → alice,carol).
            
            
          

          

            
              New threshold
              How many of the new set must sign after the change.
            
            
          

          

            
              Signers
              Quorum of the current members (before the change).
            
            
          

          

            
          

          
    
            
  • Under-threshold — one signer when threshold is 2 → panic sigs_ok=1.
    • 
            
  • Happy rotate — enough current signers → members update, nonce++.
    • 
            
  • Stale nonce — after a rotate, a stale digest fails (sigs_ok=0).
    • 
            
  • Ex-member — removed member as signer → member_matches drops.
    • 
          

        

        

      

    


    
    

      

        

          
Chapter 7

          
Multi-person approve

          
Real separate machines: each person approves with their own keystore and wallet. Coordination is the chain — no signature files.

        

        

          
Values to enter

          

            
              Registry account id
              The treasury council.
            
            
          

          

            
              Target ContractId
              32-byte hex of the contract finalize will call_raw.
            
            
          

          

            
              Function
              Exported method name on the target.
            
            
          

          

            
              Call args (hex)
              Opaque rkyv payload; empty allowed. Canonical display on approve — never trust a free-text summary.
            
            
          

          

            
              Deadline (block)
              0 = contract default TTL from propose height.
            
            
          

          

            
            
          

          

            
              Proposal id
              From create hint / next id (usually 0 for the first).
            
            
          

          

            
              Approve as
              One local signing identity that is a member.
            
            
          

          

          
          

            
            
            
            
          

          
On machine B, open this same chapter with Bob’s store and only press approve.

        

        

      

    


    
    

      

        

          
Chapter 8

          
PM council resolve

          
Collect M-of-N secure BLS partials for a prediction-market resolve over the collector, then submit when the threshold is met. Digest is council-resolve.v2 (binds PM contract id, registry account, threshold, market, outcome) — never trust the summary alone.

        

        

          
Init + push

          

            
              Market id
              On-chain market under review.
            
            
          

          

            
              Winning outcome
              0 or 1.
            
            
          

          

            
              PM ContractId
              Legacy prediction-market 32-byte hex.
            
            
          

          

            
              Registry account
              Dispute-council account id.
            
            
          

          

            
              Threshold
              Client-side gate before submit (usually account threshold).
            
            
          

          

            
              Summary (untrusted)
              Human hint only — signers must check market + outcome.
            
            
          

          

            
            
          

          

            
              Blob id (digest hex)
              From init, or pick from the list below.
            
            
          

          

            
              Sign as
              Local signing identity that is a council member.
            
            
          

          

          
          

            
            
            
            
          

          

          
Reuse Setup for collector status and Cast for identities. Gas payer need not be a council member.
